# Botanik Bahçesi Yönetim Sistemi

Web Tabanlı Programlama dersi dönem projesi.

## Proje Hakkında
Kullanıcıların kendi bitki koleksiyonlarını yöetebildiği bir web uygulaması.
Kayıt ve giriş sistemi, bitki ekleme, listeleme, düzenleme ve silme özellikleri var.

## Kullanılan Teknolojiler
- PHP
- MySQL
- Bootstrap 5

## Kurulum
1. XAMPP kur ve çalıştır
2. botanik klasörünü htdocs içine koy
3. phpMyAdmin de botanik adında veritabanı oluştur
4. SQL dosyasını import et
5. http://localhost/botanik adresine git
